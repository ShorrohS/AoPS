CONTENT TRANSFORMATION RULES
====================================================

For every existing lesson:

1. Read the original lesson.
2. Extract the core idea.
3. Determine the simplest intuition.
4. Transform it into a story.
5. Build a narrative around characters.
6. Replace technical jargon with understandable metaphors.
7. Preserve conceptual correctness.
8. Keep explanations age appropriate.

The goal is:

Understand first.
Technical details later.
