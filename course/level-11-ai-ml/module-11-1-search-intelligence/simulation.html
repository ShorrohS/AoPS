Breadth-First Search (BFS) explores all neighbours at the current depth before moving deeper. It always finds the shortest path in an unweighted graph. Queue-based: FIFO order guarantees level-by-level expansion.

Depth-First Search (DFS) dives deep along one path before backtracking. Stack-based (or recursive). It does not guarantee the shortest path but uses less memory than BFS and is often faster at finding any path in a deep graph.

A* Search combines the cost to reach a node (g) with a heuristic estimate of the remaining distance (h). It expands the node with the lowest f = g + h first. With an admissible heuristic (never overestimates), A* always finds the optimal path and explores far fewer nodes than BFS.
