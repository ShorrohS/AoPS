Linear regression finds the line of best fit. It minimises the Mean Squared Error (MSE) — the average squared distance between predictions and actual values. Gradient descent adjusts slope (m) and intercept (b) iteratively until the loss is minimised.

Logistic regression predicts probability of class membership. It applies a sigmoid function to a linear combination of features: σ(wx + b). The output is always between 0 and 1. The decision boundary is where the output equals 0.5.
