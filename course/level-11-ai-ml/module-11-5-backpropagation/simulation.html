Backpropagation is the chain rule applied to computation graphs. If L = f(g(x)), then dL/dx = (dL/df)·(df/dg)·(dg/dx). The gradient flows backward through every operation, multiplying local derivatives at each step. This is how every modern neural network learns.

Every neural network operation builds a computation graph. During the forward pass, values flow left to right. During backpropagation, gradients flow right to left, multiplied by the local derivative at each node. Click Step Backward to watch gradients propagate.

Gradient descent uses the gradient to minimise loss. At each step: w ← w − η·(∂L/∂w). The learning rate η controls step size. Too large: overshoot and diverge. Too small: slow convergence. Watch gradient descent navigate a 2D loss surface.
