ReAct = Reasoning + Acting. The agent loops: Think (what do I need to do?) → Act (call a tool) → Observe (process the result) → repeat until done. This interleaving of reasoning and action lets LLMs solve multi-step problems that require external information.

Agents need memory to operate across turns and sessions. Working memory = the current context window. Episodic memory = past interactions stored and retrieved by embedding similarity. Semantic memory = learned facts. Procedural memory = learned skills/tool use patterns.
