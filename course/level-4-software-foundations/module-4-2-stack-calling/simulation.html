Stack Canary — How It Works
A stack canary is a random value placed between local variables and the return address:

[buffer 16 bytes]
[canary ← 0xDEAD_BEEF_CAFE_1234]
[saved RBP 8 bytes]
[return addr 8 bytes]

Before RET, the function checks the canary. If it changed → abort() before the corrupted return address is used.
