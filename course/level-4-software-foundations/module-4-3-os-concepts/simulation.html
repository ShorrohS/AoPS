Trace system calls made by a program that opens, reads, and writes a file. Each syscall crosses from user space (ring 3) into the kernel (ring 0) and back. Step through one at a time.
Program: cat hello.txt
fd = open("hello.txt", O_RDONLY);
n = read(fd, buf, 64);
write(1, buf, n);
close(fd);
exit(0);
Syscall path:
User calls open() → libc wrapper → sets rax=#2, rdi=path → syscall instr → CPU to ring 0 → kernel opens file → return fd in rax → back to ring 3
