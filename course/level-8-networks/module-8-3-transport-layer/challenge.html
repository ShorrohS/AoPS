Part E — Window and Throughput

  1. A TCP connection over a satellite link has RTT = 600ms and packet loss rate = 0.1%. Using the Mathis formula: throughput ≈ MSS / (RTT × √(loss)), calculate the maximum achievable throughput with MSS = 1460 bytes.

  2. Compare: for the same link, what window size would a single TCP connection need to fully utilise a 100 Mbps link? (throughput = window / RTT)

Part C.7+8 — UDP server/client 
# Server
import socket
s = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
s.bind(('', 9001))
while True:
    data, addr = s.recvfrom(1024)
    print(f"From {addr}: {data.decode()}")
    s.sendto(data, addr)

# Client with timeout
import socket, time
c = socket.socket(socket.AF_INET, socket.SOCK_DGRAM)
c.settimeout(0.5)
for i in range(1, 6):
    msg = f"message {i}".encode()
    t0 = time.perf_counter()
    c.sendto(msg, ('127.0.0.1', 9001))
    try:
        data, _ = c.recvfrom(1024)
        rtt = (time.perf_counter() - t0) * 1000
        print(f"Reply {i}: {data.decode()}, RTT={rtt:.2f}ms")
    except socket.timeout:
        print(f"Message {i}: TIMEOUT")
Part E.15 — Mathis formula

throughput ≈ MSS / (RTT × √loss) = 1460 / (0.6 × √0.001) = 1460 / (0.6 × 0.0316) = 1460 / 0.01897 ≈ 76,962 bytes/s ≈ 615 Kbps.

For 100 Mbps: window = throughput × RTT = 12,500,000 bytes/s × 0.6s = 7,500,000 bytes ≈ 7.5 MB. A 16-bit window field (max 65,535 bytes) would limit throughput to ~872 Kbps — hence TCP Window Scaling (RFC 7323) which multiplies the window by 2^scale, enabling multi-MB windows.
