TCP's three-way handshake establishes a connection. SYN synchronises sequence numbers. SYN-ACK confirms and synchronises in the other direction. ACK completes the setup. Only then does data flow.

The sliding window allows multiple unacknowledged segments in flight. Window size = how many bytes can be sent before waiting for an ACK. A larger window = higher throughput on high-latency links.

> Throughput = window_size / RTT. Drop triggers fast retransmit after 3 duplicate ACKs.
TCP congestion control adapts the send rate. Slow Start doubles cwnd each RTT until ssthresh. Congestion Avoidance grows linearly. Packet loss resets or halves cwnd depending on the algorithm.
