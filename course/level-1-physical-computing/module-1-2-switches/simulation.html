How a relay works — a small control current energises a coil → electromagnet attracts the armature → contacts close → large output circuit switches. The two circuits never touch.

Key insight: The control coil and output contacts are in completely separate circuits. A 5mA signal can switch a 10A load. This isolation is why relays are still used in cars and industrial equipment today.
Self-latching relay — once SET, the relay holds its own state through its own contacts, even after the SET button is released. This is the first 1-bit memory cell.
0
Stored bit (relay state)
Event log:
Memory principle: The relay's own contacts are wired in parallel with the SET button. Once SET closes the relay, the relay's contacts provide an alternative current path — it holds itself closed. RESET breaks this path by opening the power supply briefly.
AND, OR, NOT from relay switches — toggle the inputs and watch the output and truth table respond. Series switches → AND logic. Parallel switches → OR logic. Normally-closed contacts → NOT logic.
