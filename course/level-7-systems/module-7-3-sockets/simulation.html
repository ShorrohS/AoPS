The TCP three-way handshake establishes a connection. SYN → SYN-ACK → ACK. Each step synchronises sequence numbers. Only after all three packets does data flow begin.

An echo server receives data and sends it back. This is the "Hello World" of socket programming. Every message goes through: recv() on the server, sendall() back to the client.
Client → Server → Client
0Sent
0Received
0Total bytes
Server code
import socket

s = socket.socket()
s.bind(('', 8080))
s.listen(5)
conn, addr = s.accept()

while True:
  data = conn.recv(1024)
  if not data: break
  conn.sendall(data) # echo back
> TCP guarantees delivery and order — no lost messages, no duplicates.
