> Built-ins (cd, exit) run in the shell process. External commands use fork()+exec().
fork() copies the process. exec() replaces it. The shell forks a child, then the child calls exec() with the command. The parent waits. Between fork and exec, the child can redirect file descriptors — this is how piping and redirection work.
Process tree
File descriptors
> fork() returns child PID to parent, 0 to child. exec() never returns on success.
Pipes connect stdout of one process to stdin of the next. `ls | grep .py` creates a kernel buffer. ls writes to it; grep reads from it. The shell sets up the pipe before fork, then uses dup2() to redirect file descriptors.
