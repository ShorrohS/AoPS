From bytes to pixels — the critical rendering path. When a browser receives HTML, it runs through a deterministic pipeline: parse HTML → build DOM → parse CSS → build CSSOM → combine into Render Tree → Layout → Paint → Composite. Each stage must finish before the next can begin.

The Render Tree = DOM ∩ CSSOM. The browser combines the DOM and CSSOM to produce a render tree containing only visible nodes with computed styles. Nodes with display:none are excluded entirely. visibility:hidden nodes stay in the tree but paint nothing.

Render Tree (visible nodes only)
Layout (reflow) recalculates geometry. Paint redraws pixels. Composition assembles layers. Changing width triggers reflow + repaint. Changing color triggers repaint only. Changing transform or opacity only triggers composition — the GPU handles it, no CPU layout recalculation needed.
