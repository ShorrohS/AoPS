Merge Sort: divide → conquer → combine. Recursively split the array in half, sort each half, then merge the two sorted halves. Always O(n log n) regardless of input. Stable sort.

Quicksort: partition around a pivot, recurse on both sides. Average O(n log n) but O(n²) worst case with bad pivot choices. Three-way partition handles duplicates in O(n).

Radix Sort beats the O(n log n) lower bound. Sort integers digit by digit using counting sort as a stable subroutine. O(d·n) where d = digits. No comparisons — works outside the comparison model.
