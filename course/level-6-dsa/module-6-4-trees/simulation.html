BST property
For any node with key k:
• All left subtree keys < k
• All right subtree keys > k

This enables O(log n) search — like binary search on a dynamic structure.
> Insert keys and watch the BST property maintained at every node.
Four ways to visit every node. In-order produces sorted output. Pre-order serialises the tree structure. Post-order processes children before parents. Level-order explores breadth-first.
