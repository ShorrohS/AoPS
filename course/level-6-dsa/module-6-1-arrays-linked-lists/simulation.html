A dynamic array doubles capacity when full. Appending is O(1) amortised — most appends are instant; occasional resizes copy all elements but happen infrequently. Inserting in the middle is O(n) — everything shifts.

A singly linked list stores nodes anywhere in memory. Each node holds data + a pointer to the next node. Prepend is O(1) — just update the head. Traversal is O(n) — follow pointers one by one.
