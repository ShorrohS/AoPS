SR (Set-Reset) Latch — the simplest 1-bit memory cell. Once Set, it holds Q=1 even after S returns to 0. Once Reset, it holds Q=0. The forbidden state (S=R=1) makes both outputs undefined. Built from two cross-coupled NOR gates.

Two NOR gates cross-coupled. Output Q feeds back into R's NOR gate, and Q̄ feeds back into S's NOR gate — creating the memory loop.
D Flip-Flop — captures the value of D at the rising clock edge only. Between clock edges, Q is held regardless of D changes. This edge-triggering is what makes synchronous digital systems possible — all flip-flops update at the same instant.

4-Bit Synchronous Counter — four D flip-flops sharing one clock. Counts 0000 → 1111 → 0000. Each flip-flop toggles when all lower-order flip-flops are 1. Step manually or let it run to see all 16 states.
