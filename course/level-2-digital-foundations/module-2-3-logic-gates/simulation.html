NAND is the universal gate. Every logic function can be built from NAND gates alone. This is why real chips use NAND-based standard cell libraries.
NOT from NAND
NOT A = NAND(A, A)
1 NAND gate
NOT A = 1
AND from NAND
A AND B = NAND(NAND(A,B), NAND(A,B))
2 NAND gates
A AND B = 0
OR from NAND
A OR B = NAND(NAND(A,A), NAND(B,B))
3 NAND gates (De Morgan's law)
A OR B = 0
XOR from NAND (4 gates)
G1=NAND(A,B)
G2=NAND(A,G1)
G3=NAND(B,G1)
XOR=NAND(G2,G3)
A XOR B = 0
