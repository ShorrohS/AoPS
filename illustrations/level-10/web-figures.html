Type A — Chapter Hero FIG 10-A Browser Rendering Pipeline — From Bytes to Pixels
The browser critical rendering path. Raw HTML bytes are parsed into a DOM tree (element nodes with parent-child relationships). CSS is parsed into a CSSOM (computed style tree). These are merged into the Render Tree — only visible elements, with full computed styles. The Layout stage assigns every node a precise position and size (the box model: content + padding + border + margin). Paint converts box geometry to pixels. The GPU composites layered elements into the final frame. JavaScript can trigger reflows (layout recalculation) which are expensive — a main reason why DOM manipulation performance matters and why virtual DOM libraries (React) exist.
Type C — Concept Diagram FIG 10-B CSS Box Model — Every Element Is a Layered Box
CSS Box Model. Every HTML element renders as a rectangular box with four nested layers: content (the actual text/image area), padding (space between content and border), border (visible line), and margin (transparent space that pushes other elements away). The critical gotcha: with the default box-sizing:content-box, declaring width:200px on an element with padding:20px produces a 240px wide rendered box — padding is added on top of the declared width. Modern CSS resets use box-sizing:border-box globally, where declared width includes padding and border, making layouts predictable. This is why CSS Grid and Flexbox toolkits always set * { box-sizing: border-box }.
Type D — Process Diagram FIG 10-C REST API Request/Response Lifecycle
REST API request/response cycle. The client makes an HTTP GET request to /api/users/1. The server's router matches the URL pattern to a handler function. The controller calls the database layer (SELECT WHERE id=1). The result is serialised to JSON and returned with HTTP headers including status code (200 OK), content type, and cache directives. REST uses HTTP verbs semantically: GET (read), POST (create), PUT (full replace), PATCH (partial update), DELETE. Responses are stateless — each request carries all needed context. JSON (JavaScript Object Notation) is the universal data format: human-readable, language-neutral, and directly usable in JavaScript.
