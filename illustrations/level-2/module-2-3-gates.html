Module 2.3 — Boolean Algebra and Logic Gates

Type A — Chapter Hero FIG 2.3-A Logic Gate Symbol Atlas — All 7 Standard Gates
Complete logic gate reference. Seven standard gates are shown with IEEE symbols, Boolean expressions, and truth tables. AND requires both inputs HIGH; OR requires at least one. NOT inverts. NAND (highlighted red border) is the universal gate: NOT, AND, and OR can all be synthesised from NAND gates alone. This universality means any digital circuit can be fabricated on a chip using only one type of transistor arrangement, which dramatically simplifies semiconductor manufacturing. NOR is also universal; both NAND and NOR flash memory chips derive their names from this property.
Type C — Concept Diagram FIG 2.3-B NAND Universality — Building XOR from 4 NAND Gates
XOR built from 4 NAND gates — the canonical proof of NAND universality. G1 = NAND(A,B) acts as a shared intermediate. G2 = NAND(A, G1) implements NOT(A AND NOT(AB)). G3 = NAND(B, G1) implements NOT(B AND NOT(AB)). G4 = NAND(G2, G3) combines them to produce A XOR B. The truth table verifies all four input combinations. This construction is used in CMOS logic libraries where all cells are ultimately implemented as NAND chains.
Type B — Reference Diagram FIG 2.3-C All Seven Standard Gates — Symbol · Boolean Expression · Truth Table
Complete reference for all seven standard logic gates, showing IEEE schematic symbol, Boolean expression, and full truth table. NAND and NOR are marked as universal gates — a fact of deep importance: any digital circuit, no matter how complex, can be constructed from NAND gates alone. This is why CMOS logic libraries are largely implemented as NAND chains. XOR outputs 1 when inputs differ, making it the equality tester and the sum-bit generator in binary addition.
