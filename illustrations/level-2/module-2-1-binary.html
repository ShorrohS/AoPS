Type A — Chapter Hero FIG 2.1-A Analog vs Digital — Why Noise Destroys Analog but Not Digital
Analog vs digital noise immunity. Left: an analog sine wave passes through a transmission medium with added noise. The received signal is permanently corrupted — every intermediate value is a valid voltage, so noise cannot be distinguished from data. Right: a digital square wave with the same noise added. At each receiver, a threshold comparator decides: above 2.4V → 1, below 0.4V → 0. The noise (small fluctuations) never crosses the threshold, so the signal is regenerated perfectly. This noise immunity property is why all modern computing uses binary — not because two is a convenient number, but because it creates a 40% safety margin against electrical noise.
Type C — Concept Diagram FIG 2.1-B Voltage Levels — TTL and CMOS Logic Thresholds
Logic voltage thresholds for TTL (5V, left) and CMOS (3.3V, right). Each supply voltage is divided into three zones: guaranteed HIGH output, undefined region (to be avoided), and guaranteed LOW output. The noise margins (green/grey bands) represent how much noise the signal can absorb before being misread. TTL provides ±0.4V margins. CMOS provides ±0.7V margins on a smaller supply. Key insight: any additional state (ternary, quaternary) would divide the voltage range further, shrinking each noise margin proportionally — making circuits less reliable, not more efficient.
Type C — Concept Diagram FIG 2.1-C Bits, Bytes, Words — Information Units in Binary
The binary information hierarchy. A single bit holds two states (0 or 1). Four bits (a nibble) hold 16 states — enough for one hexadecimal digit. Eight bits (a byte) hold 256 states — the ASCII character set fits in 7 bits with one spare. A 32-bit word holds over 4 billion states, sufficient for IPv4 addresses or 32-bit integers. A 64-bit word holds 1.8×10¹⁹ states — enough for modern 64-bit memory addresses. Each additional bit doubles capacity: states = 2ⁿ, so bits = log₂(states).
