Module 2.5 — Sequential Circuits: Memory from Gates

Type A — Chapter Hero FIG 2.5-A From SR Latch to D Flip-Flop — How Memory Emerges from Feedback
Left: SR (Set-Reset) latch built from two cross-coupled NOR gates. The feedback loops create bistable behaviour — when S=R=0, the latch holds its current Q value unchanged. This is the emergence of memory from pure combinational gates. The invalid state (S=R=1) forces both outputs to 0, violating the Q̄ = NOT Q invariant. Right: the D flip-flop solves the invalid state problem by eliminating the R input and using a clock signal. D data is captured only on the rising edge of CLK, making the storage synchronous and predictable. The timing diagram shows Q updating at each rising clock edge to match D's value at that moment.
Type C — Concept Diagram FIG 2.5-B 4-Bit Register — Four D Flip-Flops Sharing a Clock
A 4-bit register: four D flip-flops connected to a shared clock line. On every rising edge of CLK, all four D inputs are simultaneously sampled and stored in their respective flip-flops. The Q outputs maintain their values until the next rising edge. This synchronous, parallel capture is the foundation of CPU registers. A modern 64-bit processor register is simply 64 D flip-flops sharing a clock — conceptually identical to this diagram, scaled by 16×.
Type C — Architecture Diagram FIG 2.5-C 4-Bit Register — Four D Flip-Flops Sharing a Clock
A 4-bit register formed by four D flip-flops sharing a single clock signal. On every rising clock edge, all four D inputs are simultaneously captured and held at the Q outputs until the next rising edge. This is the fundamental storage mechanism in every processor: the CPU's general-purpose registers (e.g., x86's RAX, RBX) are 64-bit versions of exactly this structure — 64 D flip-flops, one clock, 64 bits of state held between clock cycles.
