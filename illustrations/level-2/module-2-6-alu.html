Type A — Chapter Hero FIG 2.6-A 4-Bit ALU Architecture — Inputs, Operation Select, Outputs, and Flags
4-bit ALU architecture. Two 4-bit operands A (11 = 1011) and B (5 = 0101) enter from the left. The operation select input (3 bits, selecting from 8 possible operations) currently selects ADD (000). The ALU performs the operation and outputs the 4-bit result plus a flags register. Here, 11+5=16 exceeds 4-bit capacity (max 15), so the result truncates to 0000 and the Carry Flag (CF=1) signals overflow. The Zero Flag (ZF=1) is also set because the stored result is 0. These flags are examined by conditional branch instructions to implement if/else and loop logic in software.
Type C — Concept Diagram FIG 2.6-B ALU Flags — What Each Flag Means and When It Is Set
The five essential ALU flags. Zero Flag (ZF): result is zero — used by equality comparisons (JE = "jump if equal" checks ZF=1). Carry Flag (CF): unsigned arithmetic overflow or borrow — used in multi-word arithmetic. Overflow Flag (OF): signed arithmetic overflow — distinct from CF because signed and unsigned overflow happen at different points. Sign Flag (SF): the result's most significant bit — set when the result is negative in two's complement. Parity Flag (PF): even number of 1-bits in the low byte — historically used for serial communication error detection. Every conditional instruction in machine code ultimately reduces to testing one or more of these flags.
Type B — Reference Diagram FIG 2.6-C ALU Operation Table — Control Lines, Operations, and Status Flags
ALU operation table and status flags for a minimal 4-bit ALU. Eight operations are encoded in 3 control bits, covering the essential arithmetic (ADD, SUB), logical (AND, OR, XOR, NOT), and shift (SHL, SHR) operations needed by a working processor. Four status flags capture properties of every result: Zero (result is zero — used for equality tests), Carry (result exceeds N bits — used in multi-word arithmetic), Overflow (signed arithmetic produced an incorrect result), and Negative (sign bit is set). These four bits directly drive conditional branch instructions in the CPU.
