Type A — Chapter Hero FIG 5.6-A Binary Search — Interval Halving on a Sorted Array of 32 Elements
Binary search on a 32-element sorted array. Each comparison eliminates exactly half the remaining candidates. The search interval [lo, hi] shrinks from [0,31] to [0,14] to [8,14] to [12,14] to [12,12] — found in 5 steps. The maximum steps needed equals log₂(n): for n=32 that is 5, for n=1,000,000 that is 20. Binary search requires the array to be sorted — if the data arrives in arbitrary order, the cost of maintaining sorted order (via an index or sorted insert) must be weighed against the search speedup.
Type B — Concept Diagram FIG 5.6-B Hash Table — O(1) Average Lookup via Key → Hash → Bucket
Hash table architecture. The hash function converts any key (string, integer, object) to an integer index modulo the bucket count. Keys "alice" and "eve" both hash to bucket 3 — a collision. Chaining resolves this by storing a linked list in each bucket; the worst case (all keys collide) degrades to O(n), but with a good hash function and load factor below 0.75, average performance is O(1) for insert, lookup, and delete. This is why Python dict and set, Java HashMap, and C++ unordered_map all achieve O(1) average operations — and why hash table selection and implementation is one of the most impactful data structure choices in systems programming.
Type D — Comparison Table FIG 5.6-C Search Algorithm Selection Guide — Structure, Complexity, Trade-offs
Search algorithm selection guide. Linear search requires no preconditions but scales poorly. Binary search gives O(log n) but requires sorted data. Hash tables achieve O(1) average for exact key lookup — the right choice for dictionaries, caches, and sets. Binary search trees (BSTs) support range queries and ordered iteration that hash tables cannot. Tries excel at string prefix matching (autocomplete). Bloom filters achieve space-efficient probabilistic membership testing at the cost of false positives. The choice is always driven by the query pattern, not just the complexity class.
