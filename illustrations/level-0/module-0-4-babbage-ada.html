Module 0.4 — Babbage and Ada: The First Programmers

Type A — Chapter Hero FIG 0.4-A The Analytical Engine — Babbage's Vision of a General-Purpose Computer
Left: The Difference Engine — a finite-difference calculator with six columns of toothed brass wheels. The highlighted column (Δ²) is the second-order difference register. The printing mechanism at the base stamps results directly onto paper, eliminating human transcription errors. Right: The Analytical Engine's four-component architecture. Unlike the Difference Engine, it included conditional branching — the ability to execute different instruction sequences based on computed results. This is the first complete description of a general-purpose programmable computer, 108 years before the first one was built.
Type C — Concept Diagram FIG 0.4-B Method of Finite Differences — Computing f(x) = x² Without Multiplication
The method of finite differences applied to f(x) = x². The second-order difference (Δ²) is always 2 for any quadratic — a constant. The engine exploits this: at each step it adds Δ² to Δ¹ to produce a new first difference, then adds that to the current f(x) to produce the next f(x). No multiplication is ever performed. Babbage designed columns of digit wheels, one per order of difference, connected by an addition mechanism. The same principle applies to any polynomial up to any degree.
Type B — Historical Reconstruction FIG 0.4-C Ada Lovelace's Note G — The First Algorithm, 1843
Ada Lovelace's Note G (1843) — the first published algorithm intended for machine execution. Left: manuscript style notes with the recursive Bernoulli formula and a fragment of her operation table. Centre: flowchart reconstruction showing the loop structure — Ada explicitly described the need for the engine to repeat a sequence of operations until a condition changes, which is the first documented algorithmic loop. Right: the output — Bernoulli numbers with operation counts showing the computational cost grows with n. Ada identified looping, variables, and subroutines as the three essential programming concepts, 100 years before those words were coined.
Type E — Before vs After / Comparison FIG 0.4-D Babbage's Analytical Engine vs Modern Von Neumann CPU — 186 Years Apart
Direct architectural comparison between Babbage's 1837 design and a 2024 CPU. Every major component maps exactly: The Mill (gear-based arithmetic) → ALU/FPU (transistor-based arithmetic). The Store (brass registers) → RAM/Cache (DRAM/SRAM). The Reader (punch card input) → I/O Controller (USB/PCIe). The Printer (stereotype press) → GPU/Display. The logical structure Babbage described in the 1830s is the same structure inside every computer today. What changed is purely physical — metal gears became silicon transistors.
Type F — Simulation Figure FIG 0.4-E Difference Engine Simulation — Stepping Through f(x) = x²
Static simulation view: the Difference Engine stepping through f(x) = x² in three steps. Each register panel shows the three column values: f(x), Δ¹, and Δ² (constant 2). At each step the engine performs exactly two additions — Δ² added to Δ¹, then updated Δ¹ added to f(x). The result matches x² exactly at every step, without ever performing a multiplication. Babbage's insight was that any polynomial function can be reduced to repeated addition through this method.
