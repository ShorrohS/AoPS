Type A — Chapter Hero FIG 8.2-A IPv4 Packet Header — All 13 Fields with Bit Widths
IPv4 packet header — 20 bytes minimum in 5 rows of 32 bits each. The most critical fields: Source and Destination IP (32 bits each) are the addresses every router uses to forward the packet. TTL (Time to Live) prevents routing loops — each router decrements it by 1; at 0 the packet is dropped and an ICMP Time Exceeded message is sent back. Protocol identifies the payload type (6=TCP, 17=UDP) so the receiving host knows how to parse the payload. IHL (Internet Header Length) specifies the header length in 32-bit words — necessary because the Options field makes the header variable-length. The Fragmentation fields allow large packets to be split by routers with smaller MTUs.
Type C — Process Diagram FIG 8.2-B Routing Table — Longest Prefix Match for 192.168.5.100
Routing table lookup using longest prefix match. For destination 192.168.5.100, the router tests every entry: the default route /0 always matches, /8 matches on the first octet, /16 matches on the first two octets, and /24 matches on the first three octets. The /24 entry (192.168.5.0/24) is the most specific match — more bits agree with the destination — so the packet is forwarded to next-hop 10.0.1.1 on interface eth2. This algorithm runs on every router for every packet. Modern routers implement it in hardware using TCAM (Ternary Content-Addressable Memory) at line rate — billions of lookups per second.
Type B — Concept Diagram FIG 8.2-C Subnetting and CIDR — How IP Addresses Are Allocated in Blocks
CIDR (Classless Inter-Domain Routing) notation specifies how many leading bits are the network address. 192.168.1.0/24 means the first 24 bits (the first three octets) are fixed — they identify the network — and the remaining 8 bits identify individual hosts within that network. The subnet mask (255.255.255.0) is a bitmask with 1s for network bits and 0s for host bits; bitwise AND of any address with the mask yields the network address. The first address (all host bits 0) is the network identifier and the last (all host bits 1) is the broadcast address — both are reserved. This gives 254 usable host addresses in a /24. CIDR replaced the older class-based (A/B/C) allocation, allowing arbitrary prefix lengths and much more efficient address allocation.
