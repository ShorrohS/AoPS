Module 8.1 — Physical and Data Link Layers

Type A — Chapter Hero FIG 8.1-A OSI 7-Layer Model — Encapsulation as Data Travels Down the Stack
The OSI 7-layer model with encapsulation. As data travels down the sender's stack, each layer adds its own header (and sometimes trailer): Transport adds TCP/UDP ports and sequence numbers, Network adds IP source/destination addresses, Data Link adds MAC addresses and a Frame Check Sequence. The receiver's stack strips these headers in reverse — each layer reads only its own header and passes the payload up. This layering is the key architectural principle: higher layers are completely insulated from the details of lower layers. An HTTP server does not know whether it is running over copper Ethernet, fibre optics, or Wi-Fi — the physical layer is transparent.
Type B — Reference Diagram FIG 8.1-B Ethernet II Frame Structure — Every Field Labelled with Byte Widths
Ethernet II frame structure — the Data Link Layer PDU on virtually all modern LANs. The 7-byte preamble and 1-byte Start Frame Delimiter are used by hardware for clock synchronisation and are not counted in the frame length. The 6-byte destination and source MAC addresses identify which device should receive the frame and who sent it. EtherType (0x0800 for IPv4, 0x0806 for ARP, 0x86DD for IPv6) tells the receiver how to parse the payload. The 4-byte Frame Check Sequence (CRC-32) detects transmission errors — a mismatch causes the NIC to silently discard the frame. Minimum payload is 46 bytes (padded if shorter) to ensure the frame is long enough for collision detection on half-duplex Ethernet.
Type D — Process Diagram FIG 8.1-C Encapsulation Walk-Through — HTTP Data Wrapped at Each Layer
Encapsulation walk-through for an HTTP GET request. At Layer 7 (Application), the HTTP request is plain text. Layer 4 (Transport) wraps it in a TCP segment header adding source port, destination port 80, and sequence number. Layer 3 (Network) wraps the TCP segment in an IP packet header adding source and destination IP addresses. Layer 2 (Data Link) wraps the IP packet in an Ethernet frame adding MAC addresses and a CRC trailer. Layer 1 (Physical) transmits the entire frame as electrical signals or light pulses. The receiver performs the reverse — each layer reads its header, verifies integrity, and passes the payload up. The HTTP server never sees MAC addresses; the network router never sees HTTP content.
