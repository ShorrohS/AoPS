Module 11.5 — Backpropagation and Gradient Descent
3 figures · Gradient Descent Loss Landscape · Chain Rule Backprop · Learning Rate Effects
Type A — Chapter Hero FIG 11.5-A Gradient Descent — Descending the Loss Surface to the Minimum
Gradient descent iteratively moves model parameters in the direction of steepest descent of the loss function. At each step: compute the gradient (the direction of steepest ascent), then take a small step in the opposite direction. Starting from w₀, each step reduces the loss until convergence at the minimum w*. The learning rate α controls step size — the most sensitive hyperparameter in deep learning. Batch gradient descent computes the exact gradient over all training data (accurate but slow). Stochastic gradient descent uses one sample at a time (fast but very noisy). Mini-batch gradient descent (32–512 samples per batch) balances accuracy and speed, and enables GPU parallelism. Adam (Adaptive Moment Estimation) adapts the learning rate per parameter using estimates of gradient mean and variance — the default choice for most deep learning tasks.
Type C — Process Diagram FIG 11.5-B Backpropagation — Chain Rule Gradient Flow through Computational Graph
Backpropagation is the chain rule applied systematically to a computational graph. Forward pass: compute and cache all intermediate values. Backward pass: starting from the loss, propagate gradients backward using the chain rule — at each node, multiply the upstream gradient by the node's local derivative to get the downstream gradient. The gradient of the loss with respect to weight w is computed as the product of all local derivatives along the path from w to the loss. One backward pass computes gradients for all parameters simultaneously — this is the key efficiency insight. Without backprop, computing n gradients would require n forward passes; with backprop, one backward pass suffices. PyTorch and TensorFlow implement automatic differentiation (autograd) that tracks operations during the forward pass and automatically computes gradients during the backward pass.
Type E — Comparison FIG 11.5-C Learning Rate Effects — Too Small, Optimal, Too Large
Learning rate α is the most impactful hyperparameter in deep learning training. Too small: the model converges but takes thousands more epochs — gradients are so tiny the parameters barely move. Too large: the loss oscillates wildly or diverges — each update overshoots the minimum, landing on the other side of the loss bowl. Optimal: loss decreases smoothly and converges to a low value. In practice, learning rate schedules vary α during training: start with a warmup (gradually increase from 0 to peak α), then apply cosine annealing or step decay to slowly reduce α, allowing coarse exploration early and fine refinement later. Learning rate finders (cyclical LR range test) automate the search for a good initial α before full training begins.
