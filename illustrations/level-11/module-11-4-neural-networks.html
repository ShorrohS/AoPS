Type A — Chapter Hero FIG 11.4-A Feedforward Neural Network — Layers, Neurons, Weights, Activations
Feedforward neural network with 3 input features, two hidden layers of 4 neurons each, and 2 outputs (e.g., binary class probabilities). Every neuron computes a weighted sum of its inputs (z = Σwᵢxᵢ + b) then applies an activation function (z → a). Information flows strictly left to right during forward pass. Connections between every pair of adjacent-layer neurons make this "fully connected" or "dense". The network has 3×4 + 4×4 + 4×2 = 36 weights plus 10 biases = 46 learnable parameters. During training, backpropagation computes gradients of the loss with respect to every parameter, and gradient descent updates all 46 parameters simultaneously.
Type E — Comparison FIG 11.4-B Activation Functions — Sigmoid, Tanh, ReLU, Leaky ReLU
Activation functions introduce nonlinearity — without them, a neural network of any depth would collapse to a single linear transformation. Sigmoid squashes to (0,1) — useful for final layer binary classification, but its gradient vanishes near 0 and 1, slowing deep network training. Tanh is zero-centred (outputs range -1 to 1), which helps gradient flow but still vanishes at extremes. ReLU (Rectified Linear Unit) max(0,z) is piecewise linear: no saturation for positive inputs, near-zero gradient cost, but "dead neurons" (units stuck at zero forever) are a risk. Leaky ReLU allows a small negative slope (α=0.01) for z<0, preventing dead neurons. ReLU and its variants dominate hidden layers in modern networks; sigmoid and softmax are used in output layers for probability outputs.
Type D — Process Diagram FIG 11.4-C Forward Pass — Layer-by-Layer Matrix Multiply + Activation
The forward pass computes network output layer by layer. Each layer applies a linear transformation (z = Wx + b — a matrix multiply plus bias) followed by a nonlinear activation (a = ReLU(z)). The final layer uses softmax for multi-class classification, which normalises logits to a probability distribution summing to 1. The loss function (cross-entropy for classification, MSE for regression) measures the discrepancy between predicted and true values. Backpropagation then efficiently computes the gradient of the loss with respect to every weight in the network using the chain rule, enabling gradient descent to update all parameters simultaneously.
