Type A — Chapter Hero FIG 11-A Neural Network Architecture — Layers, Neurons, Weights, Activations
Feed-forward neural network architecture for 3-class image classification. Three input neurons receive pixel feature values. Two hidden layers apply learned weight matrices and non-linear activation functions (ReLU: max(0,z)). The output layer with softmax activation produces a probability distribution over classes — here 84% Dog, 12% Cat, 4% Fish. The highlighted red connection shows weight w=0.7 on the path from x₁ to h₂. Each neuron computes z = Σ(wᵢ·xᵢ) + b (linear combination plus bias), then a = σ(z) (non-linear activation). The non-linearity is essential: without it, any stack of layers collapses to a single linear transformation, removing all representational capacity.
Type D — Process Diagram FIG 11-B Gradient Descent — Descending the Loss Surface
Gradient descent on the loss landscape. The loss surface (left) shows how the loss L varies as weight w changes. The training process descends the surface by repeatedly moving opposite the gradient (∂L/∂w) — the direction of steepest ascent. Each step: w ← w − η·∂L/∂w where η is the learning rate. Too large η causes overshooting past the minimum; too small causes extremely slow convergence. The training loop (right) has four steps: forward pass (compute prediction ŷ), compute loss (measure error between ŷ and true label y), backward pass (compute all gradients via the chain rule — this is backpropagation), and weight update. This loop is repeated over the entire dataset multiple times (epochs) until the loss converges.
