Type A — Chapter Hero FIG 11.2-A Vectors and the Dot Product — Geometric and Algebraic Views
The dot product is the fundamental operation of machine learning. Algebraically: a · b = Σ(aᵢ × bᵢ). Geometrically: a · b = |a| |b| cos(θ), measuring how much two vectors "align". When cos(θ) = 1, vectors point in the same direction (maximum similarity). When cos(θ) = 0, they are perpendicular (zero similarity). In neural networks, each neuron computes a weighted dot product of its inputs. In transformers, attention scores are dot products between query and key vectors. In recommendation systems, user and item vectors are compared by cosine similarity. Every regression, classification, and neural network operation ultimately reduces to dot products — linear algebra is the language of ML.
Type B — Concept Diagram FIG 11.2-B Matrix Multiplication — Row × Column Dot Products
Matrix multiplication computes C[i][j] as the dot product of row i of A and column j of B. Dimensions: (m×k) × (k×n) = (m×n). The inner dimensions k must match — this is the "shapes must be compatible" error every ML engineer encounters. In a neural network, a fully-connected layer computes output = W × input + b: the weight matrix W transforms an input feature vector into output activations. Processing a batch of N samples simultaneously: (N×features) × (features×outputs) = (N×outputs). This single matrix multiply processes the entire batch in parallel — exactly what GPUs are designed for. Modern GPU tensor cores perform thousands of matrix multiplications simultaneously, enabling training of billion-parameter models.
Type C — Concept Diagram FIG 11.2-C Linear Transformations — Matrices as Geometric Operations
Matrices as geometric transformations. The identity matrix leaves vectors unchanged. A diagonal scaling matrix stretches along axes. A rotation matrix [[cos θ, -sin θ], [sin θ, cos θ]] rotates without changing shape or size. A shear matrix tilts the space. A rank-deficient projection matrix collapses a dimension (information is lost — not invertible). Neural networks are sequences of such transformations: each layer applies a weight matrix (linear transformation) followed by a nonlinear activation function. Without nonlinearity, any sequence of linear transformations collapses to a single linear transformation. The power of deep learning comes from composing many nonlinear transformations to approximate arbitrarily complex functions.
