Type A — Chapter Hero FIG 11.3-A Linear Regression — Minimising Squared Residuals to Fit a Line
Linear regression finds the line ŷ = wx + b that minimises the Mean Squared Error (MSE) — the average squared residual (vertical distance from each data point to the line). The closed-form normal equation (XᵀX)⁻¹Xᵀy solves the optimum in one shot but requires inverting a matrix — O(n³) in the number of features. For large datasets, gradient descent iterates: compute the MSE gradient with respect to w and b, then take a small step in the downhill direction. Learning rate α controls step size — too large and it diverges, too small and it converges slowly. Linear regression is the foundation of all supervised learning: neural networks are nonlinear regression models.
Type B — Concept Diagram FIG 11.3-B Logistic Regression — Sigmoid Curve and Decision Boundary
Logistic regression extends linear regression to binary classification by passing the linear score z = wx + b through the sigmoid function σ(z) = 1/(1+e^{-z}), which squashes any real number to (0, 1) — a probability. The model predicts Class 1 when P(y=1|x) > 0.5, which corresponds to z > 0 — the decision boundary. The boundary is linear in feature space (a hyperplane). Training minimises binary cross-entropy loss: -[y log(p) + (1-y) log(1-p)], which penalises confident wrong predictions much more heavily than MSE would. Despite its name, logistic regression is a classification algorithm. It is still widely used because it is fast, interpretable, and naturally outputs calibrated probabilities.
Type E — Comparison FIG 11.3-C Bias-Variance Tradeoff — Underfitting, Good Fit, Overfitting
The bias-variance tradeoff — the central challenge of supervised learning. An underfitting model (high bias) is too simple to capture the true pattern, producing high error on both training and test data. An overfitting model (high variance) is so complex it memorises training noise — it fits every training point perfectly but fails to generalise, producing low training error but high test error. The "good fit" lies between these extremes: a model that captures the true signal without fitting noise. Solutions to overfitting: regularisation (L1/L2 penalties on weights), dropout (neural networks), early stopping, cross-validation to select model complexity, and more training data. Solutions to underfitting: increase model capacity, add features, train longer.
