Type A — Chapter Hero FIG 6A-A Data Structure Atlas — Seven Foundational Structures
Seven foundational data structures. Array: contiguous memory, O(1) index access, fixed size. Linked List: non-contiguous nodes with pointers, O(n) search, O(1) head insert. Stack (LIFO): push/pop at top only — used for call stack, undo history, expression parsing. Queue (FIFO): enqueue at tail, dequeue at head — BFS, scheduling. Hash Table: key → hash → bucket, average O(1) get/set with chaining for collision resolution. Binary Search Tree: left < parent < right invariant, O(log n) average search. Graph: vertices and edges with optional weights — all network problems reduce to graph traversal.
Type C — Concept Diagram FIG 6A-B Time Complexity Comparison — Operations Across All Structures
Complexity comparison across all seven data structures. The hash table is uniquely powerful: average O(1) search, insert, and delete — but only for exact-match lookups with no ordering. The BST sacrifices the constant factor (O(log n)) but gains ordering — in-order traversal yields sorted output, and range queries are efficient. Arrays win when random access patterns dominate and the size is known. The key insight: no single structure dominates all operations — algorithm design is choosing the right structure for the dominant access pattern of each problem.
