Type A — Chapter Hero FIG 6.3-A Hash Function Step-by-Step — Turning a String Key into a Bucket Index
The djb2 hash function traced step by step on key "cat". Each character's ASCII value is mixed into a running hash via multiply-by-33-and-add — a simple but effective avalanche operation. The final 193,488,125 is reduced to a bucket index by taking modulo the table size (8), landing in bucket 5. A good hash function must be deterministic, fast, and distribute keys uniformly to minimise collisions. Real implementations like MurmurHash3 use bitwise XOR and shifts for better statistical properties and near-zero correlation between similar keys.
Type E — Comparison FIG 6.3-B Collision Resolution — Chaining vs Linear Open Addressing
Two collision resolution strategies. Separate chaining stores a linked list in each bucket — colliding keys are appended to the list. Simple and robust at high load factors but each list node requires extra memory and pointer dereferences hurt CPU cache performance. Linear probing stores all data in the array itself — on collision, it scans forward to the next empty slot. Cache-friendly because data is contiguous, but clustering (long runs of filled slots) degrades performance, and deletion requires tombstone markers to avoid breaking probe chains. Python's dict uses a variant of open addressing; Java's HashMap uses chaining.
Type D — Performance Diagram FIG 6.3-C Load Factor and Rehashing — When Performance Degrades
Load factor α = items/buckets governs hash table performance. Chaining average lookup cost grows as 1 + α/2 — manageable even at higher load factors. Linear probing cost grows as 1/(1−α), approaching infinity as α approaches 1 (table full). Most implementations trigger a rehash at α = 0.75: allocate a new array of double the size, re-hash every existing key into the new table, then discard the old one. This O(n) rehash event occurs logarithmically rarely, so the amortized cost per insert remains O(1). Python's dict uses a load factor threshold of 2/3; Java's HashMap defaults to 0.75.
