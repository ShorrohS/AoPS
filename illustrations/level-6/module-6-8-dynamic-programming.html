Type A — Chapter Hero FIG 6.8-A Longest Common Subsequence — DP Table for "ABCB" and "BCAB"
LCS DP table for "ABCB" (rows) and "BCAB" (columns). When characters match, the cell inherits the diagonal cell + 1, recording that the common subsequence can be extended. When characters differ, the cell takes the maximum of the cell above and the cell to the left — propagating the best known LCS length so far. The final answer in dp[4][4] = 3, representing "BCB". Backtracking diagonals reconstructs the actual sequence. Without memoisation the naive recursion would require O(2^n) calls; the DP table reduces this to O(m×n) — the defining transformation of dynamic programming.
Type C — Process Diagram FIG 6.8-B 0/1 Knapsack — Choosing Items to Maximise Value within Capacity W=5
0/1 Knapsack DP table with 3 items and capacity W=5. At each cell dp[i][w], we choose the better of: not taking item i (same as dp[i−1][w]) or taking item i if it fits (dp[i−1][w−wt_i] + val_i). The maximum value achievable with all 3 items and capacity 5 is 7, achieved by selecting items 1 and 2 (weights 2+3=5, values 3+4=7). Item 3 (weight 4) alone yields only 5. Backtracking from dp[3][5] recovers which items were chosen. The algorithm runs O(nW) — pseudo-polynomial time — versus an exponential 2^n exhaustive search over all item subsets.
Type B — Concept Diagram FIG 6.8-C When to Use DP — Overlapping Subproblems + Optimal Substructure
Dynamic programming decision framework. Overlapping subproblems alone justify memoisation (cache results of a top-down recursion). Optimal substructure alone may justify a greedy algorithm. Both properties together — the same subproblems recur AND the global optimum decomposes into subproblem optima — make DP the right tool. Classic DP problems: Longest Common Subsequence, Edit Distance, Coin Change, Knapsack, Matrix Chain Multiplication. Non-DP: binary search (no subproblem overlap), merge sort (no reuse of subproblems across calls), graph BFS/DFS (state visited once). Recognising the two properties is the primary skill in algorithm design interviews.
