Module 6.4 — Trees: BST, AVL, Red-Black

Type A — Chapter Hero FIG 6.4-A Binary Search Tree — Inserting [5, 3, 7, 1, 4, 6, 8] in Sequence
BST construction by inserting [5, 3, 7, 1, 4, 6, 8]. Each value navigates left if smaller than the current node, right if larger, until an empty slot is reached. This particular insertion order produces a balanced tree of height 3 — close to the theoretical minimum of ⌈log₂ 7⌉ = 3. The BST property (left subtree < root < right subtree at every node) guarantees that search, insert, and delete each require at most O(height) comparisons. The critical vulnerability: if keys arrive in sorted order, a BST degenerates into a linked list of height n, making all operations O(n). AVL and Red-Black trees prevent this.
Type C — Process Diagram FIG 6.4-B AVL Tree Rotations — LL, RR, LR, RL Cases
AVL tree rotations — the four cases that restore the balance invariant after an insert or delete. The LL case (left-left heavy) requires a single right rotation: the left child B becomes the new root, A becomes B's right child. The RR case mirrors this with a left rotation. The LR and RL cases each require two rotations: first fix the inner imbalance at the child, then apply the outer rotation at the original root. At most two rotations per insert guarantees O(log n) amortized cost. Every rotation is O(1) — just three pointer reassignments.
Type E — Comparison FIG 6.4-C Sorted Input Catastrophe — BST Degenerates, AVL Stays Balanced
The worst case for a plain BST: sorted or nearly-sorted input produces a degenerate right-skewed chain of height n — every operation degrades to O(n), the same as linear search. The AVL tree inserts the same sequence but applies rotations after insertions 3, 5, and 7, maintaining a tree of height 3. For n=1,000,000 sorted items, a BST requires up to one million comparisons to find a value; an AVL tree requires at most about 29 (⌈1.44 × log₂ 10⁶⌉). This motivates self-balancing trees: AVL for lookup-heavy workloads, Red-Black trees (used in Linux kernel and std::map) for insert-heavy workloads with slightly relaxed balance.
