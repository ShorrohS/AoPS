Type A — Chapter Hero FIG 12-A Transformer Self-Attention — Query, Key, Value Mechanism
Transformer self-attention mechanism. Each input token is projected into Query (Q), Key (K), and Value (V) vectors. Attention scores are computed as scaled dot products between all Q-K pairs: softmax(QKᵀ/√dₖ). High scores mean "these two tokens are relevant to each other." The output for each token is a weighted sum of all Value vectors, where weights come from the attention scores. In the example, "cat" attends strongly to "mat" (score 0.82) — the output representation of "cat" now contains information about the mat. This is how transformers capture long-range dependencies without recurrence. Multi-head attention runs this process in parallel N times, each head learning different relationships (syntax, semantics, coreference).
Type D — Process Diagram FIG 12-B RAG Pipeline — Retrieval-Augmented Generation
Retrieval-Augmented Generation (RAG). The offline indexing phase: documents are split into chunks (~512 tokens), each chunk is converted to a high-dimensional vector (embedding) by an embedding model, and stored in a vector database. At query time: the user's question is embedded into the same vector space, the top-k most similar document chunks are retrieved by cosine similarity search, and these chunks are prepended to the LLM's prompt as context. The LLM generates an answer grounded in the retrieved facts rather than relying on potentially stale parametric memory. RAG enables LLMs to access current information without retraining — a deployment pattern used by virtually all production AI assistants.
Type D — Process Diagram FIG 12-C AI Agent Architecture — Plan, Act, Observe, Reflect Loop
AI agent architecture. The LLM acts as a reasoning engine in a loop: observe the current state, think (chain-of-thought reasoning), select and call a tool, observe the result, and repeat until the goal is achieved. Memory gives the agent continuity: short-term (conversation context), long-term (vector store for persistent facts), and procedural (learned skills and functions). Tools extend the LLM beyond its training data: web search, code execution, file I/O, API calls, database queries. The ReAct (Reasoning + Acting) pattern interleaves explicit reasoning steps with tool actions, making the agent's decision process transparent and debuggable. This architecture underlies GitHub Copilot, Claude with tools, and autonomous coding agents.
